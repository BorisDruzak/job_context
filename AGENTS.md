
# Правила работы с репозиторием

## Порядок чтения

1. `README.md`.
2. `reports/sosnovsky-2026-06-brief.md` и `data/sosnovsky/current-status.yaml`.
3. `docs/plans/rating-improvement-plan-2026.md`.
4. Действующая методика в `data/methodology/indicators-2026.yaml`.
5. `data/ratings/sosnovsky-history.csv` и `data/sosnovsky/monthly-details.yaml`.
6. Карта ответственности и поручения.

## Правила интерпретации

- Не выдавать `operator_note` за нормативное требование.
- Не выдавать `inference` за официальный комментарий.
- Пустое значение не означает ноль.
- Выполненная работа считается отражённой в рейтинге только после появления в официальной выгрузке.
- При расхождении приоритет: методика периода -> официальная выгрузка -> презентация/протокол -> операторское пояснение -> аналитический вывод.
- Не назначать ИТ-отдел владельцем профильного результата без документа.

## Обновление новым месяцем

Зарегистрировать источник, добавить полный CSV, обновить историю и детализацию Сосновского МО, сверить расчёт, обновить текущий статус, краткую сводку и план, затем запустить `python -m pytest -q` и `python scripts/validate_data.py`.
