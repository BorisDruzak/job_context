
# Правила работы с репозиторием

## Порядок чтения

1. `README.md`.
2. `data/sosnovsky/current-status.yaml`.
3. Действующая методика в `data/methodology/indicators-2026.yaml`.
4. `data/ratings/sosnovsky-history.csv` и `data/sosnovsky/monthly-details.yaml`.
5. Карта ответственности и поручения.

## Правила интерпретации

- Не выдавать `operator_note` за нормативное требование.
- Не выдавать `inference` за официальный комментарий.
- Пустое значение не означает ноль.
- При расхождении приоритет: методика периода -> официальная выгрузка -> презентация/протокол -> операторское пояснение -> аналитический вывод.
- Не назначать ИТ-отдел владельцем профильного результата без документа.

## Обновление новым месяцем

Зарегистрировать источник, добавить полный CSV, обновить историю и детализацию Сосновского МО, сверить расчёт, обновить статус и отчёт, затем запустить `python -m pytest -q` и `python scripts/validate_data.py`.
