
# Контекст муниципальной работы

## Организация и ИТ-контур

Внутри основной организации обслуживается около 114 пользователей. После реорганизации отдел также сопровождает отдельные функции удалённых учреждений, включая Directum и удалённое подключение. В отделе два сотрудника.

Техническая зона включает сеть, VPN, Windows AD, Linux, сетевые ресурсы, сетевую часть печати, телефонию, ВКС, рабочие места и государственные системы. Этот репозиторий посвящён не технической конфигурации, а муниципальным показателям, рейтингам и поручениям.

## Роль по рейтингам

Профильные отделы фактически исполняют значительную часть показателей, а отдел пользователя отслеживает сроки, помогает, собирает сведения и участвует в ответах. При этом ответственность за результат нередко предъявляется отделу наравне с предметными подразделениями. Это создаёт ответственность без достаточных полномочий.

## Поручения подкомиссии

Примерно раз в квартал после ВКС поступает набор поручений. Многие пункты требуют действий профильных подразделений, управляющих компаний, подведомственных учреждений или внешних организаций. Фактическая роль отдела по таким пунктам — координатор, контроль и техническая поддержка, если иное не закреплено отдельно.

## Термины данных

- `official`: значение непосредственно из методики, выгрузки или презентации.
- `operator_note`: пояснение пользователя о фактическом процессе.
- `inference`: аналитический вывод, который нельзя выдавать за официальный факт.
