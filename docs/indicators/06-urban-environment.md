# 6. Цифровая зрелость городской среды

**Код:** `urban_environment`  
**Источник методики:** `methodology-2026-order-61`  
**Базовый вес:** 1/14  
**Периодичность:** monthly  

## Расчёт

`average(P6.1, P6.2, P6.3)`

## Источник данных

ГИС ЖКХ, ГЖИ и данные ОМС

## Подпоказатели и условия

- **gosuslugi_dom_users**: users / population * 100%
- **electronic_general_meetings**: electronic_meetings / all_meetings * 100%; if denominator=0 then 0
- **max_chats_40_plus**: chats_with_40_plus / all_MKD_chats * 100%

## Сосновский МО

**Фактические роли отдела:** coordinator.  
**Контролируемость:** low.

`operator_note`: Основной проблемный показатель. Собрания, приложение и набор жителей в чаты требуют действий ЖКХ, УК, собственников и жителей вне прямого подчинения отдела.

## Автоматизация

Автоматизировать следует сбор доказательств, сроки, ответственных, эскалации и историю значений. Автоматизация не должна подменять предметного владельца и не должна назначать отдел исполнителем работы вне его полномочий.
