# 2. Использование Платформы обратной связи

**Код:** `pos`  
**Источник методики:** `methodology-2026-order-61`  
**Базовый вес:** 1/14  
**Периодичность:** monthly  

## Расчёт

`sum(awarded_subindicator_points) / sum(max_subindicator_points) * 100%`

## Источник данных

мониторинг ПОС

## Подпоказатели и условия

- **pos_connected_lko**: N / N0
- **pos_widgets**: (K + N) / (1 + N0)
- **pos_auto_rules**: N / N0
- **pos_auto_coordination**: (K + N) / (1 + N0)
- **pos_template_answers**: N / N0
- **pos_on_time**: N / N0
- **pos_satisfaction**: положительные оценки 4-5 / все оценки
- **pos_share**: N_ПОС / (N_59-ФЗ + N_С) * 100%
- **pos_participation**: уникальные участники / жители старше 14 лет * 100%
- **pos_surveys**: N с нарастающим итогом
- **pos_votes**: N голосований по реализуемым в текущем году проектам
- **pos_public_hearings**: слушания через ПОС / все публичные слушания * 100%

## Сосновский МО

**Фактические роли отдела:** coordinator, technical_support.  
**Контролируемость:** partial.

`operator_note`: Отдел влияет на часть рейтинга ПОС, но границы процесса пока не определены. Известны задачи по виджетам, опросам и техническим настройкам.

## Автоматизация

Автоматизировать следует сбор доказательств, сроки, ответственных, эскалации и историю значений. Автоматизация не должна подменять предметного владельца и не должна назначать отдел исполнителем работы вне его полномочий.
